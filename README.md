# Upachar.org - Commercial Home Healthcare Website

Official repository for **Upachar.org** (Transactional Care at Home / घर पर स्वास्थ्य सेवाएँ).

## 📌 Features
- 🏥 **Comprehensive Healthcare Services**: Nurse @ Home, Doctor Visits, Medical Equipment Rentals, Diagnostics & Physiotherapy.
- 🔍 **Search & Cost Comparison Tool**: Real-time search for medical procedure prices & health packages.
- 📅 **Online Appointment System**: Date & time slot picker for doorstep healthcare deployment.
- 🧪 **Home Sample Collection**: Doorstep pathology sample collection with digital WhatsApp report delivery.
- 🌐 **Bilingual (English / हिन्दी)**: Instant language switcher.
- 📱 **Multi-Country Contact Desk**: Direct WhatsApp & phone integration for **India (+91-7459977911)** & **Nepal (+977-9848094547)**.

## 🚀 How to Host on GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings -> Pages**.
3. Under **Build and deployment**, select **Source: Deploy from a branch** -> **Branch: main / (root)**.
4. Save to deploy live!
